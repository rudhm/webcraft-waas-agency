# A2Labs Brand Identity — 03 Echo Direction

## Mark Overview
The A2Labs "Echo" identity features a forward-driving geometric apex chevron with an interior repeating echo accent chevron in electric royal blue.

- **Primary Colors:**
  - Charcoal / Dark: `#0A0A0B`
  - Pure White: `#FFFFFF`
  - Echo Accent: `#2F5BFF` (Electric Royal Blue)
  - Card/Container Surface: `#141417`
  - Container Border: `#26262B`

- **Typography:**
  - Wordmark: Space Grotesk
  - "A2": Bold (Weight 700)
  - "Labs": Light (Weight 300)
  - All SVG assets contain zero-dependency vector path outlines.

## Included Assets
1. `a2labs-primary.svg` — Dark wordmark for light backgrounds
2. `a2labs-reversed.svg` — Pure white wordmark for dark backgrounds

4. `a2labs-brand-board.svg` — Vector brand board
